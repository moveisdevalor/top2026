# TOP 20 — Móveis de Valor

Next.js 15 + Tailwind v4. Visual moderno escuro inspirado no troféu (azul/estrela).

## Rodar

```bash
npm install
npm run dev
```

Abre em http://localhost:3000.

## Estrutura

- `src/app/page.tsx` — monta as seções
- `src/components/Hero.tsx` — topo com estrela animada
- `src/components/Sections.tsx` — Sobre, Categorias, Pilares, FAQ, Edições, CTA, Footer
- `src/components/Star.tsx` — SVG da estrela
- `src/app/globals.css` — tema (cores, fontes, animações)
